# Chrome Extension – Tabs Manager

A simple Chrome extension built using **HTML**, **CSS**, and **JavaScript** that helps manage browser tabs efficiently.  
This repository contains both the extension source code and a live demo UI.

## Live Demo (UI Preview)
👉 https://chrome-extension-aadi.netlify.app/

> Note: The live demo showcases the UI only. Chrome extension functionality works only when loaded in Chrome.

---

## Features
- Save current tab or custom input
- View saved tabs
- Delete all saved entries
- Uses Chrome Extension APIs
- Lightweight and fast

---

## Tech Stack
- HTML5
- CSS3
- Vanilla JavaScript
- Chrome Extensions API
